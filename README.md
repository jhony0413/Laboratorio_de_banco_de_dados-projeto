Visão geral:

relatorio_apresentacao-a1: representa a soma de todos os artefatos, à exceção dos scripts e códigos SQL, em um único documento.

/docs: representa todos os documentos separadamente. Nele é contido: 

Escopo e Regras de Negócio; 

Modelo Conceitual;

Dicionário de Dados;

Modelo lógico;

Documento de normalização.

/sql: representa todos os scripts e códigos SQL. Nele é contido:

ddl.sql para criação do banco de dados; 

carga.sql para inserção inicial de dados; 

consultas.sql para executar consultas e operações.

Tema:

Gerenciador lógico de loja.

Escopo:

O Sistema Gerenciador de Loja (SGL) tem como objetivo fornecer uma solução centralizada e robusta para o gerenciamento das operações relacionadas à comercialização, fornecimento e logística de produtos. O sistema atende comerciantes no controle de entidades fundamentais, englobando clientes, vendedores e fornecedores. Além disso, gerencia estoques, o catálogo de produtos organizados por categorias hierárquicas, e assegura a rastreabilidade completa sobre pedidos, transações de pagamentos e histórico de movimentações.
